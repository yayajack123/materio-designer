# Design system create page plan

- **Goal:** Provide a dedicated interactive Design System studio at `/create` (`layout: 'blank'`, `public: true`) inspired by `ui.shadcn.com/create`, accessible from the public header navbar and the admin shell top navbar (vertical and horizontal layouts), with Copy AI Prompt and Download How-To `.zip` outputs.
- **Files:** `pages/create.vue`, `components/design-system/create/CreateCustomizerPanel.vue`, `components/design-system/create/CreateExportDialog.vue`, `utils/designSystemCreate.ts`, `utils/zipArchive.ts`, top navbar links in `pages/landing.vue`, `layouts/components/DefaultLayoutWithVerticalNav.vue`, and `layouts/components/DefaultLayoutWithHorizontalNav.vue`, plus updates to `spec/design.md`, `docs/components.md`, and `docs/architecture.md`.
- **Component gap note:** `TheCustomizer.vue` mutates layout cookies globally, hides below `1280px`, and lacks preset, neutral-surface, font, radius, table-mode, prompt, and `.zip` export controls; `TemplatePrompt.vue` only renders static prompt strings. Two studio-scoped components (`CreateCustomizerPanel` and `CreateExportDialog`) isolate interactive token previewing and multi-file setup inspection without altering global customizer behavior or adding npm dependencies.
- **Reuse:** `LandingCardsShowcase`, `LandingCrudShowcase`, `LandingFormStepperShowcase`, `LandingFoundationsShowcase`, `CodeHighlight`, `NavbarThemeSwitcher`, `DialogCloseBtn`, `VNodeRenderer`, `getBrandThemeColors()`, and Vuetify primitives (`VTabs`, `VSelect`, `VColorPicker`, `VMenu`, `VTextField`, `VNavigationDrawer`, `VDialog`, `VSnackbar`, `VTooltip`, `VBtn`, `IconBtn`, `VChip`).
- **State, tokens, and interactions:** Studio chrome keeps `Poppins`, semantic `surface`/`background`/`primary`/`secondary` colors, 4px spacing, and pill `VBtn` defaults. Brand and base-neutral colors update Vuetify light/dark themes live while mounted and restore original colors on unmount; font, corner radius, button shape, card style, and density apply strictly inside `.create-preview-stage` via CSS custom properties and data attributes. URL query parameters (`URLSearchParams`) encode non-default selections for sharing. Per user confirmation, the studio includes an explicit toggle between `Mobile cards` and `Scrollable table` for the `CRUD & Table` preview tab, and navbar access lives in the top header bars only.
- **Export outputs:** One-click `Copy AI setup prompt` (Clipboard API + fallback + `role="status"` live region) and `Download how-to (.zip)` generated client-side via `utils/zipArchive.ts` (`STORE` + CRC-32, zero external packages), bundling `HOW_TO_SETUP.md`, `AI_SETUP_PROMPT.md`, `.env.example`, `vuetify-overrides.md`, and `design-tokens.json`.
- **Validation:** Verify generated ZIP integrity via Python `zipfile`, run `pnpm lint:check` and `pnpm build`, and verify diff scope preserves all existing workspace changes.
